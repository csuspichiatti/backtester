# Backtester

Backtester de estrategias de la flota MultiWhale sobre datos OHLCV de Binance Futures.

Parte de la flota de bots de trading automatizado (Python + ccxt, API de Bitget).

## Configuración

Las credenciales se leen desde variables de entorno / `config.env` (no incluido en el repo).

> Las credenciales de este repositorio fueron reemplazadas por placeholders antes de publicar.
